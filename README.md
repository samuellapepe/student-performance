# **Using Multiple Linear Regression to Analyze Student Academic Performance**
Proyek ini merupakan proyek analisis data kinerja siswa berdasarkan berbagai faktor seperti keikutsertaan dalam kegiatan ekstrakurikuler, nilai akademik, dan data demografis lainnya. Analisis dilakukan menggunakan metode statistik dan visualisasi data.

## 📁 **Dataset**
Dataset yang digunakan adalah dataset performa student yang diperoleh dari Kaggle. Dataset dapat diunduh [disini.](https://drive.google.com/file/d/1ewQSQPJdh78iWf7AvPx51eDWjw7Knsi8/view?usp=sharing)

## 🛠️ **Tools & Library**
* Python
* NumPy, Pandas
* SciPy (untuk uji ANOVA)
* Matplotlib (visualisasi)

## 🧪 **Analisis Statistik**
Notebook ini menggunakan ANOVA (Analysis of Variance) untuk menguji apakah perbedaan antara rata-rata kelompok signifikan secara statistik.

**Fungsi Kustom:**
Notebook menyertakan fungsi ANOVATAB() untuk menghitung tabel ANOVA lengkap meliputi SSR, SSE, MSE, nilai F, dan p-value.
